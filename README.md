# SC HANDBUCH

Dein Begleiter durch das Verse: ein inoffizielles deutsches Handbuch für Star Citizen mit Tutorials, Tasten (QWERTZ), Berufen, Einsätzen, Schiffen, Werkzeugen und aktuellen Bugs.

Live: https://plexxy94.github.io/SCHandbuch/

## Aufbau

- `index.html`: die ganze Seite, Ansichten per Hash (`#mining`, `#schiffe`, `#ccu-radar` …)
- `ships.js`, `ships-detail.js`, `sticks.js`: Schiffs- und HOSAS-Daten
- `news.json`, `mining.json`, `ccu.json`, `pledge.json`, `pledge-history.json`: Daten, die GitHub Actions regelmäßig aktualisiert
- `tools/`: Abruf-Skripte (nur Python-Standardbibliothek)
- `fonts/`: Schriften, lokal eingebunden
- `REDESIGN_PLAN.md`: Stand und Risiken des Redesigns „Tactical Glass“

Keine Cookies, kein Tracking, kein Build-Schritt.
